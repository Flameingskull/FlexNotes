# FlexNotes code map: everything outside `data/` and `ui/`

One part of the code map; the index is `docs/CODEMAP.md`. Source root: `app/src/main/java/com/fitlens/companion/` (paths are relative to it).
**Keep it current:** a build that adds, moves or renames a file here, or changes what one does, updates this part in
the same commit.

## Other
| File | Owns |
| --- | --- |
| `report/PdfReport.kt` | The PDF progress report (dark or light), drawn on `android.graphics.pdf`; `PageWriter`, `Palette` (`DARK` / `LIGHT`), `paint`, `fill`, `wrap`, the page constants and `PdfReport.lineChart` are `internal`, shared with the Medications report |
| `report/MedicationReport.kt` | The Medications-only PDF for a doctor (#205): `MedicationReportOptions` (range, medications, patient name, schedules, adherence, graphs, dose log, comments, light by default) and `create`: heading with disclaimer, current medications with their schedules, phases, doses (with any taper, #234) and dose changes, an adherence table, AS NEEDED (#233: each as-needed medication's times taken, days, total and most in a day, outside adherence), a graph per medication, the dose log table and comments. No workout, body or photo data. Since #223: a Symptoms section (`symptoms` option: per symptom the count, average, lowest, highest and latest rating, a `lineChart` and notes) and a Site column in the dose log (`siteName`; long names `clip`ped to their column). #213: `body` (body measurement names; any makes it an appointment summary, `summary`, titled `mdr_title_summary`): `bodyValues` gives each its count, latest with the change from the first, lowest, highest and a graph, read from the body area only |
| `report/EmergencyCardPdf.kt` | The emergency card (#215): `draw` lays it out on a canvas `PW` wide and returns the height; `pdf` (one A4 page, scaled down when long, measured first through a `Picture`) and `png` (twice the size, cut to the content), light by default |
| `video/FrameRenderer.kt`, `video/VideoExporter.kt` | Slideshow frames and MP4 export; `SlideOptions.words` (`SlideWords`) carries the frames' time since the first photo (`since`, off by default as `showSince`, #267), "≈ 3d before" and pose names from `strings.xml` (#94) |
| `branding/` (repo root) | The owner's final art, used unedited (see `CLAUDE.md` rule 4): `full-body-icon-source.jpg` (also as `flexnotes-icon-source.png`, and `flexnotes-icon-512.png` for the store and README) and `torso/torso-icon-source.jpg`. Launcher: `res/mipmap-anydpi-v26/ic_launcher.xml`, the full body in the safe zone (`mipmap-*/ic_launcher_foreground.png`) over `@color/ic_launcher_background` (its edge colour). Full body behind every screen: `res/drawable-nodpi/backdrop_character.png` (`ui/design/Backdrop.kt`). All of them were recoloured from purple to black and the app's gold in 1.0.71 by `branding/recolour_black_gold.py` (launcher background `#0C0C0C`). Torso: `drawable-*dpi/notification_character.png` (the notification large icon, 64dp, letterboxed on its own background) and `search_character.png` (38 × 24dp, `ui/design/SearchIcon.kt`) |
| `App.kt` | `Application`: sets `AppHooks` (#309), initialises `Store` and `Settings`, then starts `AutoBackup` |
| `DisplayText.kt` | #309, #320: words `data/`, `report/` and `video/` need, so none of them imports `ui/`: `poseText` (the `Poses.all` keys), `countParts` ("3 Takedowns"), `siteName` (an injection site's name), `defOrder` and `describeSet` (a set as one line, "60 kg · 8 reps"), and for the medication screens and report `phaseText` (where a run is by weekday date), `scheduleSummary`, `phaseLength`, `taperText`, `rangeText` and `flagText` ("▲ High" / "▼ Low"). Screens import them from `data`. |
| `CanvasBrand.kt` | #320: the brand for what is drawn on an Android `Canvas` (PDF reports, slideshow frames, share images): `CanvasColors` (the shared brand colours as ARGB ints, `withAlpha` rounding as Compose does; `ui.Brand` builds its matching colours from them) and `BrandFonts` (Manrope `Typeface`s, loaded in `App`). `LayeringTest` fails if `data/`, `report/` or `video/` mention `ui` or Compose; `CanvasColorsTest` pins the colours to `Brand`. |
| `AppHooks.kt` | #309: what `data/` needs from `ui/` without importing it: `accent` (notification colour int), `openApp(context)` (the notification tap intent) and `dataChanged()` (redraws the widget). Set once in `App.onCreate`; safe defaults. `AutoBackup`, `LogReminders`, `MedReminders` and `Store` use it; a new notification or refresh in `data/` must too, never import `ui.Brand` / `MainActivity` / `TodayWidgets`. |
| `docs/plans/` (repo root) | Plans, one live roadmap: `2026-10-24-roadmap.md` (Status block, issue map, builds, specs) |
| `docs/reference/` (repo root) | Owner-supplied reference material that issues cite by section: `training-load-energy-expenditure.md` (session RPE and load, ACWR bands, MET calories and sport METs; header lists how FlexNotes applies it, #240–#247, and what it doesn't adopt) |
