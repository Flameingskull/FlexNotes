## Pre-push checklist (from the failed first runs in earlier plans)

- Database bump: `Db.VERSION` +1, an `onUpgrade` migration that keeps rows, a migration test, and the exported
  schema JSON committed in the same commit (1.0.130, 1.0.153).
- New Material 3 experimental APIs carry `@OptIn` (1.0.160).
- Apostrophes in `strings.xml` are escaped (1.0.145).
- Test expectations rechecked against the code they test (1.0.146).
- New dependencies: check for classpath clashes (1.0.142, Guava) and the merged manifest has no `INTERNET`.
- Update the code map (`docs/CODEMAP.md` and the part in `docs/codemap/`), `RELEASE_NOTES.md`, this Status block and
  the tracker plan item.
